# Gemini API: `generateContent` / `streamGenerateContent`

Reference for the Google Gemini API (Generative Language API, `v1beta`) content
generation methods. Compiled from the official
[generate-content API reference](https://ai.google.dev/api/generate-content.md.txt)
and the `google.ai.generativelanguage.v1beta` protos
(for `Content`/`Part`/`ToolConfig`, which the reference page links to but does
not inline).

Conventions used below:

- All JSON field names are **camelCase**. Requests are parsed with proto3 JSON
  rules, so snake_case aliases (e.g. `system_instruction`) are also accepted;
  responses always emit camelCase.
- `bytes` fields are base64-encoded strings in JSON. `int64`-typed fields
  (e.g. `Schema.minItems`) are JSON strings. `Duration` is a string like
  `"3.5s"`. `Timestamp` is an RFC 3339 string.
- "Req" column: R = required, O = optional, Out = output only.

## Endpoints

| Method | HTTP |
|---|---|
| `models.generateContent` | `POST https://generativelanguage.googleapis.com/v1beta/{model=models/*}:generateContent` |
| `models.streamGenerateContent` | `POST https://generativelanguage.googleapis.com/v1beta/{model=models/*}:streamGenerateContent` (use `?alt=sse` for SSE) |

Path parameter: `model` (string, required) — model resource name in the form
`models/{model}`, e.g. `models/gemini-2.5-flash`. Tuned models use
`tunedModels/{name}`.

Authentication: API key, either as the `x-goog-api-key: $GEMINI_API_KEY`
header or the `?key=$GEMINI_API_KEY` query parameter. Body is JSON
(`Content-Type: application/json`).

Both methods take the same request body (`GenerateContentRequest`).
`generateContent` returns a single `GenerateContentResponse`;
`streamGenerateContent` returns a stream of them (see [Streaming](#streaming)).

## Request body: `GenerateContentRequest`

| Field | Type | Req | Description |
|---|---|---|---|
| `contents[]` | `Content` | R | Current conversation. Single item for one-shot; full history + latest message for multi-turn chat. |
| `tools[]` | `Tool` | O | Tools the model may use (function declarations, Google Search, code execution, ...). |
| `toolConfig` | `ToolConfig` | O | Configuration for the tools in the request. |
| `safetySettings[]` | `SafetySetting` | O | Per-category blocking thresholds; at most one entry per category. Applied to both prompt and candidates; overrides defaults for the listed categories. |
| `systemInstruction` | `Content` | O | Developer system instruction(s). Currently text only; `role` may be omitted. |
| `generationConfig` | `GenerationConfig` | O | Generation and output options. |
| `cachedContent` | string | O | Name of explicit cached content used as context, format `cachedContents/{cachedContent}`. |
| `serviceTier` | enum `ServiceTier` | O | Service tier of the request. |
| `store` | boolean | O | Request-level logging behavior; overrides the project-level logging config. |

```json
{
  "contents": [
    {"role": "user", "parts": [{"text": "Explain how AI works in a few words"}]}
  ],
  "systemInstruction": {"parts": [{"text": "You are a concise assistant."}]},
  "generationConfig": {"temperature": 0.7, "maxOutputTokens": 256}
}
```

### `Content`

The multi-part content of a single message.

| Field | Type | Req | Description |
|---|---|---|---|
| `parts[]` | `Part` | R | Ordered parts making up one message; parts may have different MIME types. |
| `role` | string | O | Producer of the content: `"user"` or `"model"`. Recommended for multi-turn; may be unset for single-turn or `systemInstruction`. |

### `Part`

A `Part` holds exactly one variant of the `data` union, plus optional
metadata. If `inlineData` is used it must carry a fixed IANA MIME type.

| Field | Type | Req | Description |
|---|---|---|---|
| `text` | string | union `data` | Inline text. |
| `inlineData` | `Blob` | union `data` | Inline media bytes (base64). |
| `functionCall` | `FunctionCall` | union `data` | Model-predicted function call (model output; echo back in history). |
| `functionResponse` | `FunctionResponse` | union `data` | Client-provided result of a `FunctionCall` (sent in the next turn). |
| `fileData` | `FileData` | union `data` | URI-based data (e.g. Files API URI). |
| `executableCode` | `ExecutableCode` | union `data` | Code generated by the model for the code-execution tool. |
| `codeExecutionResult` | `CodeExecutionResult` | union `data` | Result of executing `executableCode`; always follows the `executableCode` part. |
| `videoMetadata` | `VideoMetadata` | union `metadata`, O | Video preprocessing options; only valid when the part is video `inlineData`/`fileData`. |
| `thought` | boolean | O | True if the part is a thought (reasoning summary) from the model. |
| `thoughtSignature` | string (bytes) | O | Opaque signature for the thought; echo it back in subsequent requests to preserve reasoning context (required with function calling on thinking models). |
| `partMetadata` | object (`Struct`) | O | Custom metadata attached to the part (arbitrary JSON object). |

#### `Blob`

| Field | Type | Req | Description |
|---|---|---|---|
| `mimeType` | string | R | IANA MIME type of the data, e.g. `image/png`, `image/jpeg`; unsupported types return an error. |
| `data` | string (bytes) | R | Base64-encoded raw bytes. Do not send text as bytes; use `text`. |

#### `FileData`

| Field | Type | Req | Description |
|---|---|---|---|
| `mimeType` | string | O | IANA MIME type of the source data. |
| `fileUri` | string | R | URI of the file (typically a Files API `file.uri`). |

#### `VideoMetadata`

| Field | Type | Req | Description |
|---|---|---|---|
| `startOffset` | string (Duration) | O | Start offset into the video, e.g. `"60s"`. |
| `endOffset` | string (Duration) | O | End offset into the video. |
| `fps` | number | O | Frame sampling rate sent to the model; default 1.0, range (0.0, 24.0]. |

#### `FunctionCall`

| Field | Type | Req | Description |
|---|---|---|---|
| `id` | string | O | Unique id of the call; if populated, the client returns a `FunctionResponse` with the matching `id`. |
| `name` | string | R | Name of the function to call. |
| `args` | object (`Struct`) | O | Function arguments as a JSON object. |

#### `FunctionResponse`

| Field | Type | Req | Description |
|---|---|---|---|
| `id` | string | O | Id of the `FunctionCall` this responds to. |
| `name` | string | R | Name of the called function. |
| `response` | object (`Struct`) | R | Function output as a JSON object (any keys, e.g. `"output"`, `"result"`; use `"error"` to report failure). |
| `parts[]` | `FunctionResponsePart` | O | Ordered media parts of the response; each holds `inlineData` (`{mimeType, data}` blob). |
| `willContinue` | boolean | O | Signals more responses will follow (generator-style). Only for `NON_BLOCKING` calls. |
| `scheduling` | enum `Scheduling` | O | How to schedule the response in the conversation: `SILENT`, `WHEN_IDLE`, `INTERRUPT` (default `WHEN_IDLE`). Only for `NON_BLOCKING` calls. |

#### `ExecutableCode`

| Field | Type | Req | Description |
|---|---|---|---|
| `language` | enum | R | `LANGUAGE_UNSPECIFIED`, `PYTHON` (Python >= 3.10, numpy/simpy available). |
| `code` | string | R | The code to execute. |

#### `CodeExecutionResult`

| Field | Type | Req | Description |
|---|---|---|---|
| `outcome` | enum | R | `OUTCOME_UNSPECIFIED`, `OUTCOME_OK`, `OUTCOME_FAILED` (see `output` for stderr), `OUTCOME_DEADLINE_EXCEEDED`. |
| `output` | string | O | stdout on success; stderr or other description otherwise. |

### `Tool`

Each list entry may set one or more of these tool types:

| Field | Type | Description |
|---|---|---|
| `functionDeclarations[]` | `FunctionDeclaration` | Functions the model may call. The model returns a `functionCall` part; the client executes it and replies with a `functionResponse` part. |
| `googleSearch` | `GoogleSearch` | Google Search grounding. Fields: `timeRangeFilter` (`Interval`: `startTime`/`endTime` RFC 3339, start inclusive / end exclusive), `searchTypes` (`{webSearch: {}, imageSearch: {}}`, web enabled by default). |
| `googleSearchRetrieval` | `GoogleSearchRetrieval` | Legacy search-retrieval grounding. Field: `dynamicRetrievalConfig` (`mode`: `MODE_UNSPECIFIED` = always retrieve, `MODE_DYNAMIC` = retrieve when needed; `dynamicThreshold`: number). |
| `codeExecution` | `CodeExecution` | Empty object `{}`. Lets the model generate and run code (produces `executableCode` / `codeExecutionResult` parts). |
| `urlContext` | `UrlContext` | Empty object `{}`. URL context retrieval (fetches URLs referenced in the prompt). |
| `computerUse` | `ComputerUse` | Computer control. Fields: `environment` (required; `ENVIRONMENT_BROWSER`, `ENVIRONMENT_MOBILE`, `ENVIRONMENT_DESKTOP`), `excludedPredefinedFunctions[]`, `enablePromptInjectionDetection`, `disabledSafetyPolicies[]`. |
| `fileSearch` | `FileSearch` | Semantic retrieval from file search stores. Fields: `fileSearchStoreNames[]` (required, e.g. `fileSearchStores/my-store-123`), `metadataFilter`, `topK`. |
| `mcpServers[]` | `McpServer` | MCP servers the model may call. Fields: `name`, `streamableHttpTransport` (`url`, `headers` map, `timeout`, `sseReadTimeout`, `terminateOnClose`). |
| `googleMaps` | `GoogleMaps` | Geospatial grounding. Field: `enableWidget` (boolean; returns `googleMapsWidgetContextToken` in grounding metadata). |

#### `FunctionDeclaration`

| Field | Type | Req | Description |
|---|---|---|---|
| `name` | string | R | Function name: `a-z A-Z 0-9`, underscores, colons, dots, dashes; max length 128. |
| `description` | string | R | Brief description of the function. |
| `behavior` | enum | O | `BLOCKING` (default; wait for the response) or `NON_BLOCKING`. Only supported by the Live (BidiGenerateContent) API. |
| `parameters` | `Schema` | O | Parameters as an OpenAPI 3.0.3-subset `Schema` object. Mutually exclusive with `parametersJsonSchema`. |
| `parametersJsonSchema` | JSON value | O | Parameters as raw [JSON Schema](https://json-schema.org/) describing an object. Mutually exclusive with `parameters`. |
| `response` | `Schema` | O | Function output schema (`Schema` object). Mutually exclusive with `responseJsonSchema`. |
| `responseJsonSchema` | JSON value | O | Function output as raw JSON Schema. Mutually exclusive with `response`. |

#### `Schema` (OpenAPI-subset type used by `parameters` / `responseSchema`)

Fields: `type` (required enum: `STRING`, `NUMBER`, `INTEGER`, `BOOLEAN`,
`ARRAY`, `OBJECT`, `NULL`), `format`, `title`, `description`, `nullable`,
`enum[]` (strings, for STRING with `format: "enum"`), `items` (Schema, for
ARRAY), `maxItems`/`minItems` (int64 strings), `properties` (map name →
Schema, for OBJECT), `required[]`, `minProperties`/`maxProperties`,
`minimum`/`maximum` (numbers, for INTEGER/NUMBER), `minLength`/`maxLength`,
`pattern`, `example`, `anyOf[]` (Schemas), `propertyOrdering[]` (non-standard;
controls property order in output), `default` (documentation only).

### `ToolConfig`

| Field | Type | Req | Description |
|---|---|---|---|
| `functionCallingConfig` | `FunctionCallingConfig` | O | Function calling behavior. |
| `retrievalConfig` | `RetrievalConfig` | O | Retrieval context: `latLng` (`{latitude, longitude}` user location), `languageCode` (BCP-47). |

`FunctionCallingConfig`:

| Field | Type | Req | Description |
|---|---|---|---|
| `mode` | enum `Mode` | O | Default `AUTO`. |
| `allowedFunctionNames[]` | string | O | Restricts which functions may be called; only valid when `mode` is `ANY` or `VALIDATED`. |

`Mode` values:

| Value | Meaning |
|---|---|
| `MODE_UNSPECIFIED` | Unused default. |
| `AUTO` | Model chooses between a function call and a natural-language reply. |
| `ANY` | Model must emit a function call (from `allowedFunctionNames` if set). |
| `NONE` | Model must not call functions. |
| `VALIDATED` | Like `AUTO`, but function calls are validated via constrained decoding. |

### `SafetySetting`

| Field | Type | Req | Description |
|---|---|---|---|
| `category` | enum `HarmCategory` | R | Category this setting applies to. |
| `threshold` | enum `HarmBlockThreshold` | R | Probability level at and above which content is blocked. |

Categories accepted in request `safetySettings`: `HARM_CATEGORY_HATE_SPEECH`,
`HARM_CATEGORY_SEXUALLY_EXPLICIT`, `HARM_CATEGORY_DANGEROUS_CONTENT`,
`HARM_CATEGORY_HARASSMENT`, `HARM_CATEGORY_CIVIC_INTEGRITY` (deprecated),
`HARM_CATEGORY_JAILBREAK`. The full `HarmCategory` enum additionally has
`HARM_CATEGORY_UNSPECIFIED` and image variants seen in response ratings:
`HARM_CATEGORY_IMAGE_HATE`, `HARM_CATEGORY_IMAGE_DANGEROUS_CONTENT`,
`HARM_CATEGORY_IMAGE_HARASSMENT`, `HARM_CATEGORY_IMAGE_SEXUALLY_EXPLICIT`.

`HarmBlockThreshold` values:

| Value | Meaning |
|---|---|
| `HARM_BLOCK_THRESHOLD_UNSPECIFIED` | Unspecified. |
| `BLOCK_LOW_AND_ABOVE` | Only `NEGLIGIBLE` allowed. |
| `BLOCK_MEDIUM_AND_ABOVE` | `NEGLIGIBLE` and `LOW` allowed. |
| `BLOCK_ONLY_HIGH` | `NEGLIGIBLE`, `LOW`, `MEDIUM` allowed. |
| `BLOCK_NONE` | All content allowed. |
| `OFF` | Safety filter disabled for the category. |

### `GenerationConfig`

Not all fields apply to every model.

| Field | Type | Req | Description |
|---|---|---|---|
| `stopSequences[]` | string | O | Up to 5 stop sequences; generation stops at the first occurrence (sequence not included in output). |
| `responseMimeType` | string | O | Output MIME type: `text/plain` (default), `application/json` (JSON mode), `text/x.enum` (enum string). |
| `responseSchema` | `Schema` | O | Structured-output schema (OpenAPI subset). Requires compatible `responseMimeType` (`application/json`). Deprecated in favor of `responseJsonSchema`. |
| `responseJsonSchema` | JSON value | O | Structured-output schema as raw JSON Schema; set `responseMimeType` and omit `responseSchema`. Supported keywords: `$id`, `$defs`, `$ref`, `$anchor`, `type`, `format`, `title`, `description`, `enum` (strings/numbers), `items`, `prefixItems`, `minItems`, `maxItems`, `minimum`, `maximum`, `anyOf`, `oneOf` (treated as `anyOf`), `properties`, `additionalProperties`, `required`, plus non-standard `propertyOrdering`. Cyclic `$ref` only within non-required properties. |
| `responseModalities[]` | enum `Modality` | O | Requested response modalities (`TEXT`, `IMAGE`, `AUDIO`); exact match to what the model returns. Empty = text only. |
| `candidateCount` | integer | O | Number of candidates to return (default 1). |
| `maxOutputTokens` | integer | O | Max tokens per candidate (default varies by model). |
| `temperature` | number | O | Randomness, range [0.0, 2.0] (default varies by model). |
| `topP` | number | O | Nucleus sampling cumulative probability cap. |
| `topK` | integer | O | Top-k sampling cap; some models don't allow setting it. |
| `seed` | integer | O | Decoding seed; random if unset. |
| `presencePenalty` | number | O | Binary penalty on tokens already seen in the response. |
| `frequencyPenalty` | number | O | Penalty proportional to how often each token has been used. |
| `responseLogprobs` | boolean | O | If true, include `logprobsResult` in the response. |
| `logprobs` | integer | O | Number of top logprobs per decoding step, range [0, 20]. Requires `responseLogprobs`. |
| `enableEnhancedCivicAnswers` | boolean | O | Enables enhanced civic answers (model-dependent). |
| `speechConfig` | `SpeechConfig` | O | Speech (TTS) output config. |
| `thinkingConfig` | `ThinkingConfig` | O | Thinking config; error if set on non-thinking models. |
| `imageConfig` | `ImageConfig` | O | Image generation config; error on unsupported models. |
| `mediaResolution` | enum `MediaResolution` | O | Input media resolution: `MEDIA_RESOLUTION_LOW` (64 tokens), `MEDIA_RESOLUTION_MEDIUM` (256), `MEDIA_RESOLUTION_HIGH` (zoomed reframing, 256). |
| `enableAffectiveDialog` | boolean | O | Model detects emotion and adapts responses (Live-oriented). |
| `responseFormat` | `ResponseFormatConfig` | O | Per-modality output format: `text` (`mimeType` enum `APPLICATION_JSON`/`TEXT_PLAIN`, `schema`), `audio` (`mimeType`, `delivery` `INLINE`/`URI`, `sampleRate`, `bitRate`), `image` (`mimeType` `IMAGE_JPEG`, `delivery`, `aspectRatio`, `imageSize`). |
| `translationConfig` | `TranslationConfig` | O | Translation config: `targetLanguageCode` (required, BCP-47), `echoTargetLanguage`. |

#### `ThinkingConfig`

| Field | Type | Req | Description |

| `includeThoughts` | boolean | O | Include thought-summary parts (`thought: true`) in the response when available. |
| `thinkingBudget` | integer | O | Number of thought tokens the model may generate (model-specific ranges; 0 disables thinking where supported, -1 = dynamic). |
| `thinkingLevel` | enum | O | `MINIMAL`, `LOW`, `MEDIUM`, `HIGH`. Depth of reasoning; Gemini 3+ only (error on earlier models). Alternative to `thinkingBudget`. |

| Field | Type | Req | Description |
|---|---|---|---|
| `voiceConfig` | `VoiceConfig` | O | Single-voice output: `{"prebuiltVoiceConfig": {"voiceName": "Kore"}}`. |
| `multiSpeakerVoiceConfig` | object | O | Multi-speaker TTS: `speakerVoiceConfigs[]` of `{speaker, voiceConfig}` (both required). Mutually exclusive with `voiceConfig`. |
| `languageCode` | string | O | BCP-47 code from the supported list (e.g. `en-US`, `ja-JP`, `cmn-CN`). |

#### `ImageConfig`

| Field | Type | Req | Description |
|---|---|---|---|
| `aspectRatio` | string | O | One of `1:1`, `1:4`, `4:1`, `1:8`, `8:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`. |

`SERVICE_TIER_UNSPECIFIED` (standard), `SERVICE_TIER_FLEX`,

### Request examples

Function calling:

```json
{
  "contents": [{"role": "user", "parts": [{"text": "Turn on the lights"}]}],
  "tools": [{
    "functionDeclarations": [{
      "name": "set_light_color",
      "description": "Set the light color.",
      "parameters": {
        "type": "OBJECT",
        "properties": {"rgb_hex": {"type": "STRING"}},
        "required": ["rgb_hex"]
      }
    }]
  }],
  "toolConfig": {"functionCallingConfig": {"mode": "ANY", "allowedFunctionNames": ["set_light_color"]}}
}
```

JSON mode + thinking + safety:

```json
{
  "contents": [{"parts": [{"text": "List 3 cookie recipes"}]}],
  "safetySettings": [{"category": "HARM_CATEGORY_HARASSMENT", "threshold": "BLOCK_ONLY_HIGH"}],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseJsonSchema": {
      "type": "array",
      "items": {"type": "object", "properties": {"recipeName": {"type": "string"}}, "required": ["recipeName"]}
    },
    "thinkingConfig": {"thinkingBudget": 1024, "includeThoughts": true}
  }
}
```

## Response body: `GenerateContentResponse`

The API returns either all requested candidates or none; no candidates are
returned only when the prompt itself was blocked (check `promptFeedback`).

| Field | Type | Req | Description |
|---|---|---|---|
| `candidates[]` | `Candidate` | Out | Candidate responses from the model. |
| `promptFeedback` | `PromptFeedback` | Out | Prompt content-filter feedback (set when the prompt is blocked). |
| `usageMetadata` | `UsageMetadata` | Out | Token usage for the request. |
| `modelVersion` | string | Out | Model version used, e.g. `"gemini-2.5-flash"`. |
| `responseId` | string | Out | Identifier of this response. |
| `modelStatus` | `ModelStatus` | Out | Lifecycle stage of the model: `modelStage` (`EXPERIMENTAL`, `PREVIEW`, `STABLE`, `LEGACY`, `DEPRECATED`, `RETIRED`, ...), `retirementTime` (RFC 3339), `message`. |

### `Candidate`

| Field | Type | Req | Description |
|---|---|---|---|
| `content` | `Content` | Out | Generated content (`role` is `"model"`; parts may be text, `inlineData`, `functionCall`, `executableCode`, `codeExecutionResult`, thought summaries with `thought: true`, and may carry `thoughtSignature`). |
| `finishReason` | enum `FinishReason` | Out, O | Why generation stopped; empty/absent while still generating (streaming). |
| `safetyRatings[]` | `SafetyRating` | Out | Safety ratings for the candidate; at most one per category. |
| `citationMetadata` | `CitationMetadata` | Out | Recitation/citation info for text in `content`. |
| `tokenCount` | integer | Out | Token count for this candidate. |
| `groundingAttributions[]` | `GroundingAttribution` | Out | Only for `GenerateAnswer` calls (not populated by `generateContent`). |
| `groundingMetadata` | `GroundingMetadata` | Out | Grounding metadata (populated when search/retrieval tools are used). |
| `avgLogprobs` | number | Out | Average log probability of the candidate. |
| `logprobsResult` | `LogprobsResult` | Out | Token logprobs (when `responseLogprobs` is enabled). |
| `urlContextMetadata` | `UrlContextMetadata` | Out | URL-context tool metadata. |
| `index` | integer | Out | Index of the candidate in `candidates`. |
| `finishMessage` | string | Out, O | Detail message for `finishReason`; only set when `finishReason` is set. |

| Value | Meaning |
|---|---|
| `FINISH_REASON_UNSPECIFIED` | Unused default. |
| `STOP` | Natural stop or stop sequence hit. |
| `MAX_TOKENS` | `maxOutputTokens` reached. |
| `SAFETY` | Candidate flagged for safety. |
| `RECITATION` | Candidate flagged for recitation. |
| `LANGUAGE` | Unsupported language. |
| `OTHER` | Unknown reason. |
| `BLOCKLIST` | Contains blocklisted terms. |
| `PROHIBITED_CONTENT` | Potentially prohibited content. |
| `SPII` | Potential sensitive personally identifiable information. |
| `MALFORMED_FUNCTION_CALL` | Model produced an invalid function call. |
| `IMAGE_SAFETY` | Generated image violates safety. |
| `IMAGE_PROHIBITED_CONTENT` | Generated image has prohibited content. |
| `IMAGE_RECITATION` | Image generation stopped due to recitation. |
| `IMAGE_OTHER` | Other image generation issue. |
| `NO_IMAGE` | Expected image was not generated. |
| `UNEXPECTED_TOOL_CALL` | Model called a tool but none were enabled. |
| `TOO_MANY_TOOL_CALLS` | Too many consecutive tool calls. |
| `MISSING_THOUGHT_SIGNATURE` | A required thought signature was missing in the request. |
| `MALFORMED_RESPONSE` | Malformed response. |
| `ESCALATION` | Filtered by an escalation rule. |

### `GroundingMetadata` (summary)

Returned when grounding (Google Search / file search / Maps) is used:

- `groundingChunks[]` — supporting references; each is a union of `web`
  (`uri`, `title`), `image` (`sourceUri`, `imageUri`, `title`, `domain`),
  `retrievedContext` (`uri`, `title`, `text`, `fileSearchStore`,
  `pageNumber`, `mediaId`, `customMetadata[]`), or `maps` (`uri`, `title`,
  `text`, `placeId`, `placeAnswerSources`). When streaming, each chunk only
  contains grounding chunks not already sent in previous responses.
- `groundingSupports[]` — claim-level support: `groundingChunkIndices[]`
  (indices into the accumulated `groundingChunks` across all stream
  responses), `confidenceScores[]` (0–1, same length), `renderedParts[]`
  (indices into the candidate's `content.parts`), `segment`
  (`{partIndex, startIndex, endIndex, text}`, byte offsets).
- `webSearchQueries[]`, `imageSearchQueries[]` — issued search queries.
- `searchEntryPoint` — `renderedContent` (embeddable HTML snippet), `sdkBlob`
  (base64 JSON of search-term/URL tuples). Display requirements apply.
- `retrievalMetadata.googleSearchDynamicRetrievalScore` — 0–1 score (dynamic
  retrieval only).
- `googleMapsWidgetContextToken` — token for rendering a Maps widget.

### `LogprobsResult` (summary)

`topCandidates[]` (one entry per decoding step; each has `candidates[]`
sorted by log probability descending), `chosenCandidates[]` (one per step),
`logProbabilitySum`. Each inner candidate: `{token, tokenId, logProbability}`.

### `UrlContextMetadata` (summary)

`urlMetadata[]` of `{retrievedUrl, urlRetrievalStatus}` where the status enum
is `URL_RETRIEVAL_STATUS_UNSPECIFIED` / `_SUCCESS` / `_ERROR` / `_PAYWALL` /
`_UNSAFE`.

## Streaming

`streamGenerateContent` takes the identical request body and emits a sequence
of `GenerateContentResponse` chunks. Two wire formats:

- **Default (no `alt` parameter)**: the HTTP body is a single JSON **array**
  of `GenerateContentResponse` objects, written incrementally (`[` first
  object, `,` next object, ... `]`). A client must incrementally parse the
  array to get chunks as they arrive.
- **SSE (`?alt=sse`)**: `Content-Type: text/event-stream`. Each chunk is one
  event of the form `data: <GenerateContentResponse JSON>` followed by a
  blank line. There is no `[DONE]` sentinel; the stream simply ends. Errors
  before the stream starts are plain JSON error responses; mid-stream errors
  terminate the connection.

```
POST https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse
x-goog-api-key: $GEMINI_API_KEY
Content-Type: application/json
```

### Chunk contents

Every chunk is a structurally complete `GenerateContentResponse`:

- `candidates[i].content.parts` holds the **increment** (delta) for that
  candidate — typically one text part with the next text fragment. Non-text
  parts (`functionCall`, `inlineData`, `executableCode`,
  `codeExecutionResult`) arrive as whole parts within a chunk. Thought
  summaries stream as parts with `thought: true`; `thoughtSignature` appears
  on the part it belongs to.
- `responseId` and `modelVersion` are present on every chunk (same
  `responseId` throughout the stream).
- `candidates[i].finishReason` is absent while the candidate is still
  generating and is set on that candidate's final chunk (with
  `finishMessage` if applicable). `safetyRatings`/`citationMetadata` appear
  on chunks where they apply.
- `usageMetadata`: intermediate chunks may carry partial usage (e.g. prompt
  counts); the last chunk carries the complete, final token counts. Use the
  last received `usageMetadata`.
- `promptFeedback` (block case): if the prompt is blocked, the first (and
  only) chunk has `promptFeedback.blockReason` and no candidates.
- `groundingMetadata.groundingChunks` are incremental across chunks;
  `groundingSupports[].groundingChunkIndices` index into the accumulated
  list (client must accumulate in order).

### Aggregation rules

To reconstruct the full response, group candidates by `index` and, per
candidate: append each chunk's `content.parts` in arrival order; concatenate
consecutive `text` parts that have the same `thought` flag; keep non-text
parts as-is (preserving `thoughtSignature`); take the last-seen
`finishReason`, `safetyRatings`, and `citationMetadata`; accumulate
`groundingMetadata` lists; take the final `usageMetadata`.
